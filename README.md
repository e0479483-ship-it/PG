# 个人离线训练页

生成后的离线套件包含 `my-gym.html` 和 `assets/` 媒体目录。其中有 1,324 条简体中文动作、缩略图、动画 GIF、正反面人体轮廓、训练计划和记录界面；不依赖网络服务器。**HTML 必须和 `assets/` 一起复制**，单独复制 HTML 不会有图片/GIF。多人使用时，每个人各自保存一份套件和自己的备份，数据不会自动合并。

## 重新生成

从 `/Users/theo/exercises-dataset/data/exercises.json` 读取动作数据，并将对应的 `images/` 和 `videos/` 复制到套件：

```sh
cd /Users/theo/openGym
node personal-html/build.mjs
```

每个动作详情打开时才请求对应 GIF；动作库先用静态缩略图，缩略图延迟加载。构建会输出所有中文动作对应的 GIF 和图片，媒体目录约 177 MB，传输 ZIP 约 122 MB。授权由项目所有者确认，页面在缩略图和动画下保留 © Gym visual 标注。

## 按训练部位推荐

在首页或“计划”页点**按部位推荐动作**，默认展示腿部动作。可切换胸、背、肩、手臂、核心、有氧或全身，再按器械筛选。勾选动作后，可加入当前训练、加入现有计划或新建训练日；每个新动作默认 3 组 × 8 次，之后可在计划里调整。

## 健康饮食与营养

顶部的**营养** Tab 中有 Mifflin–St Jeor TDEE 计算器、目标热量和三大营养素进度、12 个快捷食物、自定义食物、8×250ml 饮水杯和按训练场景筛选的食谱。目标、食物流水账、饮水和食谱筛选均保存在本机；“重置今日”只清除当天饮食和饮水，不会删除目标或其他训练数据。

**不要从 openGym 的 `catalogue/media` 复制素材**；本套件只从你指定的 `exercises-dataset` 获取媒体。许可与来源说明见 `NOTICE.md`。重新分发时请保留页面内的许可证面板及本目录的 NOTICE。
